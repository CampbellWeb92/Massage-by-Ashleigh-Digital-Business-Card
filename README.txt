FEATURES

- Subtle layered glitter animation behind the card

- Soft gold glow around the logo
- WhatsApp highlighted as the main contact action
- SVG icons for WhatsApp, OnlyFans and Website
- Responsive mobile layout
- QR code for saving contact details
- Save Contact (.vcf) button
- Reduced-motion accessibility support
- No call button included

HOW TO PUBLISH
1. Upload the contents of this folder to your web hosting.
2. Keep the file and folder structure exactly as supplied.
3. Make sure index.html is in the website root.
4. Open the page in a browser and test WhatsApp, OnlyFans, Website and Save Contact.
